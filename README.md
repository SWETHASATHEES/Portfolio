# DataFlix — Netflix-inspired Portfolio

A responsive, dark, streaming-platform-inspired portfolio for data analytics, machine learning, and AI projects. Built with plain HTML, CSS, and JavaScript. No build tools or package installation required.

## Preview locally
1. Download and extract this folder.
2. Open `index.html` in a browser.
3. Edit `index.html`, `styles.css`, and `script.js` as needed.

## Personalise before publishing
In `index.html`:
- Replace `YOUR.EMAIL@example.com` with your email.
- Replace `YOUR-GITHUB-USERNAME` with your GitHub username.
- Replace `YOUR-LINKEDIN-URL` with your LinkedIn profile URL.
- Add a CV link if you want a downloadable résumé.
- Add GitHub repository links, project screenshots, and verified final metrics to the project cards and modal details.
- Update the profile, education, and skills content so it accurately reflects your current status.
In `styles.css`, change the CSS variables at the top to adjust the theme.
In `script.js`, update the `projectData` object to edit the project detail popups.

Skill bars are illustrative placeholders. Change them or remove the percentages if you do not want to communicate subjective proficiency levels. Project descriptions are starter summaries; confirm every statement and metric before making the site public.

## Publish using GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `dataflix-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, `README.md`, and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then click **Save**.
6. Wait for GitHub Pages to publish. The site URL will appear on the Pages settings screen.

A custom domain is optional. GitHub Pages can host this static site for free on a public repository.

## Notes
- The Google Fonts import requires an internet connection; system fallbacks are provided.
- No personal information is sent to a backend. The contact action uses an email link.
- The design is inspired by streaming-service layouts, but is not affiliated with or endorsed by Netflix.
